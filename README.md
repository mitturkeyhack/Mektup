# 💌 Geleceğe Mektup

Bugünkü hislerini, hayallerini ve dualarını mühürle — zamanı gelince gelecekteki sen açsın.

- ✍️ Kâğıt rengi, ruh hâli ve ilham sorularıyla mektup yazma
- 📅 Modern takvim + saat seçici (1 ay … 20 yıl, ya da istediğin gün)
- 🔏 Katlanma, zarfa girme, mühür basma animasyonu
- ✈️ 🚀 🌠 🕊️ Dört farklı gönderim animasyonu
- 🔔 Zamanı gelince bildirim, mühür kırarak açma
- 🗓️ Zaman çizelgesi, gelen kutusu
